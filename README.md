# [add-on]Hyan的奇妙替身能力

## 一个简单而不失趣味的add-on

### 使用方式

下载StandAbi.mcaddon并使用我的世界基岩版打开

支持版本1.21.100以上

### add-on内容

加入了若干种新物品，可为你赋予多种奇妙能力
